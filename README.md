**Sistema de Gestao de Lojas**

Sobre o Projeto
O **sistema de gestao de lojas** e um projeto desenvolvido em Python 
com o objetivo de controlar produtos, stock e endaas em uma loja.
O sistema permite organizar as informacoes dos produtos e realizar 
diferentes operacoes relacionadas com a gestao da loja.

Este projeto utiliza conceitos como:
- Listas
- Dicionarios
- Funcoes
- Estruturas condicionais
- Ciclos de repeticao
- Variaveis boleanas
- Manipulacao de dados
- Calculos e estatisticas
- Gestao de stock e venda.

**Funcionalidads**
O sistema permite realizar operacoes como:
- Cadastrar produtos
- Listar produtos
- Procurar prdutos
- Atualizar informacoes dos produtos
- Remover produtos
- Controlar a quantidade disponivel em stock
- Registar vendas
- Calcular o valor das vendas
- Consultar estatisticas da loja
- Identificar produtos disponiveis
- Identficar produtos com pouco stock

**Tecnologias utilizadas**
Este projeto foi desenvolvido utilizando:
- Python
- Estruturas de dados(listas e dicionarios)
- Programacao estruturada
